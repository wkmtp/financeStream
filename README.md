# AI 炒股直播软件（Jetson Xavier NX）无代码实现方案

本项目给出一个**可落地的无代码/低代码实现蓝图**：
- 两个虚拟主播角色（男/女）
- DeepSeek 根据股票走势自动选热门股并生成讲解脚本
- 支持接入抖音/快手直播弹幕，按观众点名股票即时点评
- 直播画面实时显示股票行情、技术指标、时间曲线
- 语音采用本地开源高拟人 TTS（双音色）
- 面向 NVIDIA Jetson Xavier NX 部署

---

## 1. 角色与能力

### 角色 A（男主播）
- 风格：理性、偏技术面
- 内容：趋势、均线、成交量、风险位

### 角色 B（女主播）
- 风格：亲和、偏事件驱动
- 内容：行业新闻、资金面、短线机会与风险提示

两角色轮播发言，形成“对话式直播”。

---

## 2. 核心业务流程

1. **行情采集**（每 3~5 秒）
   - 拉取 A 股/港股/美股实时或准实时行情（按数据源权限）
   - 计算涨跌幅、成交额、换手、量比、MACD/KDJ/MA 等指标

2. **热点筛选**（每 30~60 秒）
   - 根据规则 + LLM 综合评分选 TopN 热门股票
   - 规则示例：涨速、成交额突增、新闻热度、弹幕提及次数

3. **脚本生成（DeepSeek）**
   - 输入：当前热点池 + 指标 + 新闻摘要 + 风险模板
   - 输出：男主播文案、女主播文案、图表讲解点、风险提示

4. **语音合成（本地 TTS）**
   - 男/女使用不同 speaker
   - 输出低延迟音频片段（2~8 秒）并拼接

5. **直播合成与推流**
   - 背景：K 线 + 分时 + 成交量 + 技术曲线
   - 图层：主播立绘/数字人、字幕条、弹幕问题、风险提示
   - FFmpeg/OBS 推送至抖音/快手 RTMP

6. **互动问答**
   - 监听弹幕“分析 xxx”“看看 xxx”
   - 自动提取股票代码并插入高优先级点评队列

---

## 3. 无代码/低代码技术栈（推荐）

- **工作流编排**：n8n（可视化流程）
- **LLM 应用编排**：Dify（Prompt、知识库、工作流）
- **本地 TTS 服务**：GPT-SoVITS（双角色音色）
- **行情与指标服务**：Python 微服务（FastAPI）
- **前端图表面板**：Node-RED Dashboard / Grafana / 自定义 Web 面板
- **直播导播**：OBS + obs-websocket + FFmpeg
- **弹幕接入**：抖音/快手开放平台（或合规第三方中间层）

> 说明：严格“零代码”在行情计算、平台接口适配环节通常不可避免少量脚本，因此采用“AI 驱动 + 无代码为主 + 少量胶水代码”的工程化方案。

---

## 4. Jetson Xavier NX 部署建议

- 系统：JetPack 5.x（Ubuntu 20.04）
- 建议模式：15W/20W + 散热
- 容器：Docker + docker compose

### 资源分配建议
- DeepSeek 调用：云 API（降低本地算力压力）
- TTS：本地 GPU 推理（TensorRT/ONNX 优化优先）
- 图表渲染与推流：独立进程，避免与 TTS 抢占 GPU 峰值

### 延迟目标（可运营）
- 弹幕触发到播报：3~8 秒
- 自动轮播点评节拍：10~20 秒/条

---

## 5. 合规与风控

- 强制加入“仅供学习交流，不构成投资建议”固定口播与字幕
- 对高风险词（梭哈、稳赚、内幕等）做 Prompt 与后处理拦截
- 保留直播日志（文案、行情快照、弹幕、播报记录）便于审计

---

## 6. 里程碑

- **M1（1 周）**：单角色自动讲股 + 实时图表 + 本地 TTS
- **M2（2 周）**：双角色对话 + 弹幕点股 + 自动排队点评
- **M3（3~4 周）**：策略评分增强 + 多市场支持 + 稳定推流
